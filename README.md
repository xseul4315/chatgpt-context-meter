# ChatGPT Context Meter

一個簡單的 Chrome 小工具，用來快速查看目前 ChatGPT 對話的長度，大約已經走到所設定 Context 參考值的幾 %。

> 重點只有一個：**看看這個對話是不是已經太長，該不該準備換新對話。**

## 功能

安裝後，ChatGPT 右下角會顯示一個簡單的百分比：

- 🟢 0–59%：正常
- 🟡 60–74%：對話偏長
- 🟠 75–84%：建議準備換視窗
- 🔴 85% 以上：建議換新視窗

點擊百分比後，可以看到：

- 目前 Context 參考百分比
- 已計算 Token / Context 參考值
- 完整對話是否成功讀取

一般使用時，只需要看右下角的百分比即可。

---

## 使用情境

第一次使用時，預設為：

**ChatGPT 付費版 — 272k Token**

設定中也可以切換：

- **ChatGPT 付費版 — 272k**
- **ChatGPT Free / Go — 128k**
- **進階／自訂**

一般 ChatGPT 付費使用者通常維持預設值即可。

> Context 參考值不是這個對話本身的固定屬性，而是用來計算長對話比例的參考分母。

## 安裝

目前 v1.0.0 主要於 **Google Chrome** 驗證。

1. 在 GitHub Release 頁面下載 **Source code (zip)**
2. 解壓縮 ZIP
3. Chrome 開啟：

   `chrome://extensions`

4. 開啟右上角 **開發人員模式**
5. 點擊 **載入未封裝項目**
6. 選擇解壓後、內含 `manifest.json` 的資料夾
7. 重新整理 ChatGPT

安裝完成後，進入任一 ChatGPT 對話即可看到右下角百分比。

## 怎麼計算？

基本概念是：

`完整可讀對話 Token ÷ Context 參考值`

工具會嘗試讀取目前 ChatGPT 對話的完整 user / assistant 訊息，而不是只計算畫面目前載入的部分內容。

Token 計算使用瀏覽器本機的 `o200k_base` tokenizer。

因此即使長對話往上捲動時舊訊息才載入，工具仍可嘗試從完整歷史計算，而不是只統計當前畫面。

---

## 這不是 OpenAI 官方 Context Meter

ChatGPT Context Meter 顯示的是 **長對話參考值**，不是 OpenAI 官方提供的實際 Context 使用率。

工具無法知道：

- 系統提示
- Memory
- 工具定義
- 內部訊息封裝
- 後端摘要、壓縮或裁切
- 當次回答保留的輸出／推理空間

因此：

**32% 不代表模型後端實際 Context 一定正好使用了 32%。**

它比較適合用來判斷：

> 「這個聊天累積的內容是不是已經很長？」

---

## 完整歷史與快取

工具第一次讀取長對話時，可能需要幾秒鐘。

成功讀取後會建立本機統計快取，之後再次進入相同對話時，可以先使用快取，再更新最新內容。

如果無法取得完整歷史，工具會直接提示：

> 僅讀取部分內容，數字可能偏低

避免把不完整的結果誤認為完整 Context 百分比。

---

## 隱私

Token 計算在瀏覽器本機執行。

聊天正文不會傳送到第三方服務做 Token 計算。

本機快取不保存聊天全文，只保存計算與訊息識別所需的統計資料。

ChatGPT access token 不會寫入 extension storage。

## 已知限制

ChatGPT 網頁的內部 API 與頁面結構可能隨 OpenAI 更新而改變。

如果未來 ChatGPT 改版，完整歷史讀取功能可能需要跟著更新。

若遇到異常，可從工具的：

**設定 → 問題排查 → 複製診斷資訊**

取得不包含聊天正文的診斷資料。
